Write rawcopy: a file copy made of syscall.Open, Read, Write and Close, which never loses a byte and never hides an error.
What you should know
  • Open the source first, then the destination: a missing source must not leave an empty destination behind.
  • Read in chunks until Read returns 0; write each chunk with writeAll, which loops until every byte is taken.
  • Every call's error is returned, wrapped with what was being done (fmt.Errorf("open %s: %w", …)).

The spec

CommandBehaviour
rawcopy SRC DSTCopy every byte of SRC into DST (created with mode 0644, or emptied if it exists), print copied N bytes, exit with status 0.
ErrorsReturn the error; main prints rawcopy: … on standard error and exits with status 1. The error text must contain the system's words (for example no such file or directory, no space left on device).
RuleSystem calls only: no os.Open, os.Create, os.ReadFile, io.Copy.
Flags, modes and closing

syscall.Open(path, flags, mode): flags combine with |. O_RDONLY reads; O_WRONLY|O_CREAT|O_TRUNC writes, creates the file if needed and empties it if not. mode (here 0644, "owner reads and writes, others read") only matters when the file is created.

defer syscall.Close(fd) works like defer f.Close() in module 1. Use %w in fmt.Errorf, so the syscall.Errno stays inside the error and its text is printed.

Run this

$ rawcopy /tmp/big.bin /tmp/big.copy $ sha256sum /tmp/big.bin /tmp/big.copy $ rawcopy /tmp/big.bin /mnt/small/big.copy

What you should notice

  • Same fingerprint: every byte made it.
  • Copying 2 MB to a 1 MB disk ends in rawcopy: write /mnt/small/big.copy: no space left on device, exit status 1. A copy that ignored Write's results would have printed "copied 2097152 bytes".
