Write the receiving half of gosock: what nc -l 9000 > file did, as a program of your own.
What you should know
  • net.Listen("tcp", addr) gives a listener; its Accept() waits for one sender and returns a connection. Two different things, each to close.
  • A connection is a reader: io.Copy(file, conn) stores everything that arrives, and returns when the sender closes.
  • Check every error, defer every close.

The spec

CommandBehaviour
gosock recv ADDR DESTListen for TCP on ADDR (:9000 means port 9000 on every address). Accept one connection. Write every byte that arrives into the file DEST. When the sender closes, print received N bytes and exit with status 0.
ErrorsAny failure is returned from recv; the given main prints gosock: ... and exits with status 1.
How the starting code is organised

main is written. You write the body of recv: the comments name the Go function to use, you write the statements. Hover any name in the editor for its documentation. Reference: net.Listen, Accept, os.Create, io.Copy.

The checks build your code and run it on machines of their own, so nothing you do on A and B can make them pass or fail.

Run this

Now on your machines: B receives, A sends one line with nc.

$ gosock recv :9000 got.txt $ echo "hello gosock" | nc -N $B_IP 9000 $ cat got.txt

What you should notice

  • While it waits, your program sits in the kernel, inside a call named accept, and B holds a socket in LISTEN.
