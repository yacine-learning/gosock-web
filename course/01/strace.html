strace prints every system call a program makes: the course's main window into the kernel's front door. Here is how to read it.

Trace a real command

Put strace in front of any command. Its lines go to the terminal, mixed with what the command itself prints:

$ strace cat /tmp/hello.txt

What you should notice

  • One line per call: name(arguments) = result. openat returned 3, and every later line about the file starts with that 3.
  • The text appears twice: once inside read(3, "hello…") where cat received it, once inside write(1, "hello…") where it sent it to the terminal. And once more for real, because the write happened.
  • The last read returned 0: end of file. That is how cat knew it could stop.
Options you will use
OptionEffect
-o FILEwrite the trace to a file, so it does not mix with the program's own output
-e trace=read,writeonly the calls you name; -e trace=network selects all the socket calls
-p PIDattach to a program that is already running (ps shows the PIDs)

A line that stops in the middle is a call that has not returned yet: the program is waiting inside the kernel, and the rest of the line appears when the call returns. If something else must be printed meanwhile, strace marks the waiting call <unfinished ...> and completes it later on a line starting with <... resumed>.
