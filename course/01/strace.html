What you should know
  • strace CMD prints every system call the command makes, one per line: name(arguments) = result.
  • A result of -1 comes with an error name such as ENOENT; a read that returns 0 means end of file.
  • It is the course's main window on what a program really asks the kernel.
Options, and lines that stop in the middle
OptionEffect
-o FILEwrite the trace to a file, so it does not mix with the program's own output
-e trace=read,writeonly the calls you name; -e trace=network selects all the socket calls
-p PIDattach to a program that is already running (ps shows the PIDs)

A line that stops in the middle is a call that has not returned yet: the program is waiting inside the kernel. If something else must be printed meanwhile, strace marks it <unfinished ...> and completes it later on a line starting with <... resumed>.

Run this

$ strace cat /tmp/hello.txt

What you should notice

  • openat returned 3, and every later line about the file starts with that 3.
  • The text appears in read(3, "hello…"), where cat received it, then in write(1, "hello…"), where it sent it to the terminal.
  • The last read returned 0: that is how cat knew it could stop.
