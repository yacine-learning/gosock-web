Just enough Go to write your first program, and the one idea that makes it short: readers and writers. Everything below is used in the next page.

The shape of a program

package main // an executable is always package main import ( "fmt" // every package you use must be imported... "os" // ...and every import must be used ) func main() { // the program starts here fmt.Println("hello", os.Args) // os.Args: the command line }

Errors are values

Go has no exceptions. A function that can fail returns its result and an error. The caller checks it right away. You will write this shape dozens of times:

f, err := os.Open(path) // := declares f and err if err != nil { // nil means "no error" return err // pass it up to the caller } defer f.Close() // runs when this function returns

defer does not close the file now. It schedules the call for the moment the surrounding function returns. Each thing you open gets a defer Close() on the next line.

What you should notice

  • The same io.Copy line served a pipe and a file. In the next page one end is a file and the other a network connection, and the line is the same.
  • Build is the real Go compiler. Break the program on purpose (delete an import, or a )) and build again: the message gives the line and column, and clicking it takes you there.
