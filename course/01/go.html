What you should know
  • A program is package main with a func main(). Every package you use is imported, and every import must be used.
  • Go has no exceptions: a function that can fail returns its result and an error, checked right away with if err != nil.
  • defer f.Close() schedules the close for when the function returns. Everything you open gets one, on the next line.
  • io.Copy(dst, src) copies from any reader to any writer: a file, a pipe, a network connection, it does not care.
f, err := os.Open(path) // := declares f and err if err != nil { // nil means "no error" return err // pass it up to the caller } defer f.Close() // runs when this function returns n, err := io.Copy(os.Stdout, f)

io.Reader"something you can read bytes from"files, network connections, standard input…
io.Writer"something you can write bytes to"files, network connections, standard output…

io.Copy reads a chunk from the reader, writes it to the writer, and repeats until the reader says "end" (in Go: the error io.EOF, which io.Copy does not report as an error). It returns how many bytes it moved.

Run this

A 25-line program built on io.Copy. Open it, read it, press Build: the command copy appears on both machines. Then feed it a pipe, then a file:

 $ echo "from a pipe" | copy $ copy /etc/hostname

What you should notice

  • The same io.Copy line served a pipe and a file. In the next page one end is a network connection, and the line is the same.
  • Build is the real Go compiler. Break the program on purpose (delete an import) and build: the message gives line and column, and clicking it takes you there.
