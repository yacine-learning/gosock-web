Write the sending half of gosock, then move the 2 MB file with a tool that is entirely yours.
What you should know
  • net.Dial("tcp", addr) connects and returns a connection: a writer as well as a reader.
  • io.Copy(conn, file) sends the whole file; closing the connection is what tells the receiver "that's all".
  • Open the file before you connect: a missing file must not leave a half-made connection behind.

The spec

CommandBehaviour
gosock send ADDR FILEOpen FILE, connect to ADDR over TCP, send every byte, close the connection, print sent N bytes and exit with status 0.
ErrorsReturned from send, printed by main as gosock: ..., exit status 1.
References

The shape is the mirror image of recv, in the same file. Reference: os.Open, net.Dial, io.Copy.

Run this

Your receiver on B, your sender on A, the file nc carried two pages ago:

$ gosock recv :9000 big.copy $ gosock send $B_IP:9000 /tmp/big.bin $ sha256sum /tmp/big.bin $ sha256sum big.copy

What you should notice

  • Same fingerprint, and both programs exited by themselves.
  • Set Wire to slow and run it again: the send buffer on A and the receive buffer on B fill and drain while segments cross.
