Write the sending half of gosock, then move the 2 MB file from A to B with a tool that is entirely yours.

The spec

CommandBehaviour
gosock send ADDR FILEOpen FILE for reading, connect to ADDR over TCP, send every byte of the file, close the connection, print sent N bytes and exit with status 0.
ErrorsReturned from send, printed by main as gosock: ..., exit status 1. Open the file before you connect: a missing file must not leave a half-made connection behind.

The shape is the mirror image of recv, in the same file. Reference: os.Open, net.Dial, io.Copy.

The real thing

Your receiver on B, your sender on A, and the file that nc carried two pages ago:

$ gosock recv :9000 big.copy $ gosock send $B_IP:9000 /tmp/big.bin $ sha256sum /tmp/big.bin $ sha256sum big.copy

What you should notice

  • Same fingerprint on both machines, and both programs exited by themselves: closing the connection is what nc needed -N for.
  • Set Wire to slow (top right) and run the transfer again: you can watch the send buffer on A and the receive buffer on B fill and drain while segments cross the wire.
